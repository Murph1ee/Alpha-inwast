# ลุงโฉลก สถานการณ์ตลาดหลักทรัพย์ วันที่ 13 08 2015

- ลำดับในเพลย์ลิสต์: 13/20
- ช่อง: ChalokeDotCom
- วิดีโอ: https://www.youtube.com/watch?v=r4lyHXtakI8
- สถานะ: ถอดบทเรียนบางช่วงจากข้อความถอดเสียงอัตโนมัติและภาพวิดีโอต้นฉบับ

## แหล่งข้อมูลและขอบเขต

ใช้[วิดีโอต้นฉบับ](https://www.youtube.com/watch?v=r4lyHXtakI8) ความยาวประมาณ 11:11 นาที ผ่านข้อความถอดเสียงอัตโนมัติจากไฟล์ใน `video/` และตรวจภาพกราฟช่วง 2:50 กับ 5:55 ข้อความบางช่วงขาดหายหรือเพี้ยน จึงไม่ยกเป็นคำพูดตรง วันที่ 13 สิงหาคมในชื่อคลิปเป็นบริบทของคลิป ไม่ใช่วันเผยแพร่ที่ตรวจยืนยันแล้ว

## บริบทที่จำเป็น

ผู้พูดวิเคราะห์ SET ในขาลง ณ เวลานั้น โดยใช้ Elliott Wave และ Fibonacci หาเขตที่อาจหยุดลง พร้อมแยกการเด้งระยะสั้นจากการกลับแนวโน้มใหญ่ ไม่ปรากฏผลของการคาดการณ์ภายหลังในคลิป

## วิธีคิดและบทเรียน

### ข้อ 1: ใช้วิธีวัดสองแบบตรวจเขตเป้าหมายเดียวกัน

**วิธีคิดที่พบ**  
ผู้พูดวัด Fibonacci Projection จากคลื่นลงโดยใช้ราคาปิดของจุดคลื่น แทนจุดสูง–ต่ำรายวัน แล้วเทียบกับ Fibonacci Retracement ของช่วงขึ้นก่อนหน้า หากระดับ 161.8% ของ projection ใกล้กับระดับ 61.8% ของ retracement จึงให้ความสนใจบริเวณนั้นเป็นเป้าหมายที่อาจรับราคา

**หลักฐาน**  
ข้อความถอดเสียงจาก[คลิป](https://www.youtube.com/watch?v=r4lyHXtakI8) ช่วง 2:33–2:59 ระบุว่าการวัดคลื่นใช้ค่า close ไม่ใช้ high–low; ช่วง 4:50–5:18 กล่าวถึง retracement 61.8%; ช่วง 5:36–6:08 เทียบ projection กับ retracement ภาพกราฟช่วง 5:55 แสดงเส้น 161.8% และ 61.8% ใกล้บริเวณ 1,370 จุด ซึ่งเป็นระดับในกราฟปี 2015 เท่านั้น

**การตีความ**  
เห็น SET ลงในแนวโน้มใหญ่ (ตามกราฟและข้อความถอดเสียง) → วัดเป้าจากคลื่นลง (ตามข้อความถอดเสียง) → เทียบกับการย่อตัวของขาขึ้นก่อนหน้า (ตามข้อความถอดเสียง) → ได้บริเวณเป้าหมายใกล้กัน แต่ผลจริงหลังคลิปไม่ปรากฏ

**บทเรียน**  
ข้อเสนอของผู้วิเคราะห์: บันทึกจุดเริ่ม จุดจบ และชนิดราคา (close หรือ high–low) ก่อนวาด Fibonacci เพื่อให้ตรวจซ้ำได้ และถือระดับที่ซ้อนกันเป็นสมมติฐาน ไม่ใช่หลักประกันว่าจะรับอยู่

**วิธีทดลองใช้และข้อจำกัด**
- ทดลอง: เลือกกราฟ SET ย้อนหลัง 5 ช่วง ปิดข้อมูลอนาคต แล้ววัด projection กับ retracement โดยกำหนดจุดวัดล่วงหน้าและจดว่าระดับซ้อนกันหรือไม่
- สังเกตผล: จุดวัดที่ต่างกันเปลี่ยนเขตเป้าหมายมากเพียงใด และมีกรณีที่ราคาหลุดระดับหรือไม่
- ข้อจำกัด: การเลือกจุดคลื่นมีดุลยพินิจ และการซ้อนกันของสองเส้นไม่ใช่หลักฐานอิสระทั้งหมดเพราะมาจากกราฟราคาเดียวกัน
- คำถามทบทวน: ถ้าเลือกราคาสูง–ต่ำแทนราคาปิด ผลจะเปลี่ยนมากแค่ไหน?

### ข้อ 2: แยกการเด้งสวนขาลงออกจากการกลับตัวจริง

**วิธีคิดที่พบ**  
ผู้พูดสังเกตแท่งดำยาว การลงแบบ gap และแท่งลักษณะ hammer ในภาวะ oversold แล้วคาดว่าอาจเด้งสั้น แต่ยังมองแนวโน้มใหญ่เป็นขาลงและเตือนว่าการเล่นสวนต้องมีจุดออก

**หลักฐาน**  
ข้อความถอดเสียงจาก[คลิป](https://www.youtube.com/watch?v=r4lyHXtakI8) ช่วง 6:19–7:14 กล่าวถึง oversold, gap down, hammer และการเด้งช่วงสั้น; ช่วง 7:29–7:59 เตือนเรื่องการเล่นสวนแนวโน้มและจุดออก ไม่ปรากฏกติกาที่นิยาม hammer หรือจุดออกเป็นตัวเลขที่ตรวจซ้ำได้

**การตีความ**  
เห็นสัญญาณอ่อนแรงมากและแท่งกลับตัว (ตามข้อความถอดเสียง) → คาดเด้งระยะสั้น (ความเห็นผู้พูด) → ยังจำกัดกรอบว่าเป็นการสวนขาลง (ตามข้อความถอดเสียง) → ผลจริงหลังคลิปไม่ปรากฏ

**บทเรียน**  
ข้อเสนอของผู้วิเคราะห์: เขียนแยกสองข้อสรุปว่า “อาจเด้งในไม่กี่วัน” กับ “แนวโน้มใหญ่กลับเป็นขึ้น” และกำหนดหลักฐานที่จำเป็นสำหรับแต่ละข้อ

**วิธีทดลองใช้และข้อจำกัด**
- ทดลอง: เลือกกราฟขาลงย้อนหลัง 5 กรณีที่มี hammer หลังลงแรง ปิดข้อมูลอนาคต แล้วจดแผนการเด้งจำลองและจุดยกเลิกก่อนเปิดข้อมูลต่อ
- สังเกตผล: การเด้งเกิดจริงหรือไม่ และกี่ครั้งที่ตีความผิดว่าเป็นการกลับแนวโน้ม
- ข้อจำกัด: ไม่มีข้อมูลผลการใช้กติกานี้อย่างเป็นระบบหรือรายละเอียดจุดหยุดขาดทุนที่ครบ
- คำถามทบทวน: หลักฐานอะไรจึงจะทำให้ฉันเปลี่ยนจากมองว่าเด้งเป็นมองว่ากลับแนวโน้ม?
