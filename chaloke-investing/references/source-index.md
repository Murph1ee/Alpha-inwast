# ดัชนีแหล่งข้อมูล LSL1

จัดทำสำเนาเมื่อ 7 ตุลาคม 2026 จาก `LSL1` ในโครงการ lung_chaloke2 บทเรียนรายคลิปทั้ง 20 ไฟล์คงข้อความและสถานะเดิมทุกประการ อ่านเฉพาะไฟล์ที่เกี่ยวข้องกับโจทย์

## วิธีใช้หลักฐาน

1. ใช้หัวข้อในตารางเลือกบทเรียน แล้วเปิดอ่านส่วนหลักฐาน การตีความ และข้อจำกัดก่อนอ้างถึงผู้พูด
2. ลิงก์ YouTube ในตารางเป็นต้นทางที่บทเรียนระบุ ช่วงเวลาอยู่ในแต่ละบทเรียน ไม่ได้ตรวจวิดีโอหรือลิงก์ใหม่ตอนสร้าง skill
3. แยกใจความที่บทเรียนถอดจากผู้พูดออกจากการอนุมานและแบบฝึกของผู้ถอดบทเรียน ถ้าต้องยืนยันคำพูดตรง/ตัวเลข/สูตร ต้องตรวจเสียงหรือภาพต้นฉบับเพิ่ม
4. ส่วนสูตรคำนวณ กระบวนการตอบ และแบบบันทึกใน skill เป็นการประยุกต์ที่สร้างขึ้น ไม่ใช่คำสอนต้นฉบับทั้งหมด

[ภาพรวมและที่มาของ LSL1 เดิม](lessons/source-overview.md) ระบุว่ามีวิดีโอครบและใช้ข้อความถอดเสียงอัตโนมัติ แต่ยังมีคำเพี้ยนและช่วงขาดหาย แพ็กเกจนี้แนบเฉพาะบทเรียน ไม่แนบ `video/` หรือ `.tools/transcripts/` ที่ต้นฉบับกล่าวถึง
